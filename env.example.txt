# =============================================================================
# BudgetRail — Complete Environment Variable Reference
# =============================================================================
#
# FORMAT:  KEY=value_or_placeholder
#          Everything after  # ←  is an explanation.
#
# HOW TO USE FOR LOCAL DEV
# ------------------------
#   cp env.example.txt .env
#   Fill in every line marked  ← PASTE YOUR VALUE
#   Run: bun run dev
#
# HOW TO USE FOR VERCEL (production / preview)
# --------------------------------------------
#   Go to: vercel.com → arc-budgetrail → Settings → Environment Variables
#   Add ONLY the variables in Section A, B, C  (marked "ADD TO VERCEL")
#   Do NOT add Section D variables — those are local dev only
#   After adding all vars → Deployments → latest → Redeploy
#
# SECURITY RULES
# --------------
#   NEVER commit .env — it is in .gitignore
#   NEVER put a private key in a VITE_* variable — it ships to every user's browser
#   NEVER share QUOTE_SIGNER_PRIVATE_KEY or AGENT_PRIVATE_KEY in chat or email
#
